# JLPT N3 官方试题集

来源：https://www.jlpt.jp/cn/samples/sampleindex.html
使用规则：https://www.jlpt.jp/cn/policy.html

2012 年版与 2018 年第二集的试题选自 2010 年改革后的真实考试。这里的年份是出版年份，不代表对应年份某一考次的完整试卷。

- 2012：33 道文字词汇、39 道语法阅读、27 道听力，共 99 题。
- 2018：35 道文字词汇、39 道语法阅读、28 道听力，共 102 题。
- 例题不计入得分。保留官方 PDF 全文，题目页面按原始 PDF 页码生成 WebP，跨页材料一并显示。
- 听力使用官网五个完整分组 MP3，包含说明与例题；问题 1—3 为四选一，问题 4—5 为三选一。联网播放使用官网直链，公共仓库和网站不托管录音文件。
- 两卷原卷封面听力均标注约 40 分钟；公开音频实际为 40 分 26 秒及 43 分 23 秒，因此应用分别按 41 / 44 分钟计时，避免截断录音。
- 答案直接读取官方答案表，并与独立核对的答案串比较。没有把人工生成的讲解标为官方解析。
- 2012 的 N3Q2.mp3 按官网当前链接使用 sample2017/mp3/N3Q2.mp3。

本项目按官网使用规则第 1(4) 条作为免费教育网站提供 N3 图文，保留原卷署名并标明来源。原始资料的版权归原权利人所有。包含第三方作者作品的听力录音只保留官网链接及校验信息，不上传到公共仓库或发布站点。

「保存离线资料」只保存图文。个人离线听力使用「导入离线音频」：用户先从官网下载对应卷的 `N3Q1.mp3` 至 `N3Q5.mp3`，再一次选择 5 个文件；应用通过 SHA-256 校验后仅存入本机浏览器缓存，不上传。第 1(1) 条允许个人学习用途的复制及改编。学习记录备份不包含媒体文件。

来源、SHA-256、PDF 页数、音频时长和实际采用的页面列表见 sources.json。重建：

```sh
python3 tools/build_official_bank.py --source /workspace/jlpt-n3-official
```

依赖：PyMuPDF、Pillow。构建不会通过 OCR 改写试题，也不会裁掉原卷的注音、配图或跨页阅读材料。网站由 `python3 tools/build_site.py` 生成至 `_site/`，发布内容排除 MP3。
