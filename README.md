# 日和 · 日本語 / Japanstudy

适合 iPhone、iPad 与桌面浏览器的日语学习网页（PWA）。无需账号或后端；在 Safari 中添加到主屏幕后，可以从图标独立打开。通过 GitHub Pages 发布，不需要从 App Store 安装。

## 功能与当前内容

- **N3 官方真题选编**：收录官方《日本語能力試験 公式問題集》2012 卷 99 题、2018 第二卷 102 题，共 201 题，包含原卷页面、官方答案及原版听力。支持整卷、仅笔试及分科练习，按题号选择答案，交卷记分，错题和标记接入同一复习功能。2012/2018 是出版年份，题目选自 2010 年改版后的真实考试，**不是对应年份某次考试的完整历年卷**。
- **N3 原创模拟考试**：原创 102 题，按文字词汇（30 分钟）、语法阅读（70 分钟）、听力（40 分钟上限）依次交卷。支持仅笔试和 10 分钟短卷。每部分可检查作答、标记题目；交卷后才能看本轮答案与解析。刷新、锁屏或离开页面不暂停计时。题量与合成音频长度属于本应用的模拟编排。
- **词汇与汉字**：N5/N4/N3 各 30 个词汇、各 20 个汉字词，支持选择题、输入读音与混合模式。选择题适度加入近音或近义干扰项。汉字通过整词语境学习，避免将多音字强行限定为一个读音。
- **语法**：每级 20 道原创题，含每个错误选项的说明、正确用法、例句和中文译文。
- **动词变形**：32 个常用动词、12 类形态、374 个适合教学的组合；支持规范的假名和汉字作答。覆盖五段、一段、する、来る、行く、ある等例外。
- **错题与记录**：自动收录错误和未答题、重点标记、按科目筛选及搜索。连续答对两次后归入已巩固，之后答错重新进入待复习。记录存于设备本地，可导出 JSON 并在另一台设备恢复。
- **PWA**：响应式布局、主屏幕图标、首次联网缓存后的原创题离线练习。官方图文可按套保存离线；官方录音联网时从官网播放，也可导入已下载的原版 MP3 供本机离线播放。保留 `quizzes/` 中原有课堂练习和它们各自的存储数据。

官方试题和原创练习会分别标注来源。现有词汇/汉字/语法日常练习是原创基础题库，不是 N5—N3 的完整覆盖。JLPT 未公开完整词表或语法大纲，应用级别为教学参考。也可以从考试页导入个人题库；`assets/import-example.json` 给出可用格式。

练习只报告答对题数、正确率和语言知识/阅读/听力分类统计，**不能换算 JLPT 正式尺度分数或预测合格**。

## 本地运行

从仓库目录运行（无需安装前端依赖或构建）：

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

通过本机 8000 端口打开 `index.html`。JavaScript 使用原生 ES modules，应通过 HTTP 服务打开，不使用 `file://`。

## iPhone / iPad

使用 Safari 打开已发布的站点，选择「分享 → 添加到主屏幕」。应用缓存与离线功能需要 HTTPS（或本机开发环境）。首次联网加载成功后，页面与原创题库可离线使用；官方图文需在对应试题集卡片中单独保存，并等到保存完成。官方录音的离线使用步骤见下文。导入的个人题库和记录保存在 localStorage 中。

- **记录不会自动同步**。在「设置 → 导出学习记录」保存文件，再在另一设备「恢复备份」。恢复前会明确确认覆盖当前记录；未完成的练习不会跨设备转移。
- **官方听力使用原版 MP3**，联网时直接从 JLPT 官网播放，无需先导入。每个大题整组连续播放，同组翻题不中断录音。考试中允许暂停后继续或刷新后续播，不提供拖动，播放结束后不能重播；练习时可以拖动与重播。开始听力前需要手动点播放，遵守 Safari 的音频播放限制。离开页面或切换应用可能中断声音，考试计时仍继续。离线播放需先在本机导入该卷的 5 个官方 MP3。
- **原创听力使用系统日语合成语音**，设备必须提供 `ja-JP` 等日语声音。原创整卷开始前必须试音；缺少语音时可做笔试，原创听力练习会明确改为听力稿文本理解。真实听音质量与 Safari/iOS 的中断行为仍需设备验证。
- **轻触反馈**：所有按钮有轻微按压反馈，并尊重系统减少动态效果设置。浏览器支持 `navigator.vibrate` 时可在设置开启震动；iOS Safari 不开放通用 Taptic Engine 调用，iPad 通常也没有振动马达，因此不会伪装支持。
- 清理浏览器/PWA 数据可能清除本地记录。请定期备份。Safari 与独立主屏幕应用的存储隔离情况由系统决定。

## 官方试题的作答与复习

在考试页选择 2012 或 2018 官方试题集。题目保留原卷页面中的日文排版、注音、划线和配图，页面会指出当前题号；在原卷中找到对应题目后，通过下方选项编号作答。手机屏幕较小时，可点击「查看高清原图」在新窗口放大阅读。同一阅读材料或听力大题的原卷页面可能对应多道题。

官方两套试题的文字词汇限时 30 分钟、语法阅读限时 70 分钟。原卷将听力标为约 40 分钟；下载的原版录音包含例题，2012 卷总时长约 40 分 26 秒、2018 卷约 43 分 23 秒。应用将听力限时分别设为 **41 分钟、44 分钟**，以免倒计时截断整套录音。考试计时不会因暂停录音而停止。

官方题使用官方答案表判分。交卷后可核对答案、查看原卷和听力稿，并把错题加入复习；目前**没有为这 201 道官方题逐题新编中文教学解析**。日常原创语法练习继续提供错误选项解释和语法教学。分数为原始答对题数及正确率，不是 JLPT 官方尺度分数。

每套资料提供试卷 PDF、答案表、答题卡、听力稿与 5 组官网录音链接。点击对应卡片的「保存离线资料」可保存该卷图文；录音不会随网站发布，也不会由这个按钮下载。

需要离线听力时，先在官网目录下载对应卷的 `N3Q1.mp3` 至 `N3Q5.mp3`，存入 iPhone / iPad 的「文件」。然后点击该卷的「导入离线音频」，一次选择这 5 个文件。应用逐个核对 SHA-256，确认与该卷官方原版文件一致后存入当前设备的浏览器缓存，不会上传。2012 卷的第二组以官网当前链接为准，其地址中的目录为 `sample2017`。在另一设备使用时，需要再次导入。

离线资料会额外占用设备空间，浏览器回收存储后需重新保存或导入。学习记录备份只包含学习数据，不包含图片、PDF 或 MP3。

图文来自上述官方目录，保留原卷署名，并在应用中标明出处；本项目按官网使用规则第 1(4) 条作为免费教育网站提供 N3 图文。包含第三方作者作品的听力录音仅链接到官网，不上传到公共仓库或网站；本机音频导入用于个人学习。

## 题库导入

模考页支持 UTF-8 JSON，最多 3 份，每份不超过 600 KB，每部分 1—100 题。三个部分依次为词汇、语法阅读、听力；按照 N3 流程固定 30/70/40 分钟。所有题必须带来源名称、解释和唯一 ID。选择答案必须和一个选项字符串完全一致。听力可提供 `audioText`，用设备语音朗读；也可引用应用登记的官方录音与原卷图片。媒体引用会经过校验，不支持任意外部媒体地址。

下载应用中的「格式示例」或参考 `assets/import-example.json`。应用会校验字段、答案、科目及重复编号，导入后重新分配本地唯一 ID。导入题库不会上传到任何服务。

## 测试

逻辑与题库检查（Node.js 24，无 npm 依赖）：

```sh
node tests/core.test.mjs
```

真实 Chromium 交互检查（需要 Python Playwright 与 `/usr/bin/chromium`，测试自行启动临时静态服务）：

```sh
python3 tests/browser_smoke.py
python3 tests/platform_smoke.py
python3 tests/official_smoke.py
```

浏览器测试覆盖手机/平板尺寸、混合输入、解释、持久化、错题巩固、模考分段与超时、题库导入和备份恢复。平台测试覆盖 GitHub Pages 子路径、Service Worker 离线恢复，以及使用明确模拟对象的语音/触觉 API 状态处理；模拟测试不代表真机听感或马达验证。官方卷测试需要本机已有两套官网 MP3，会先通过界面导入音频，再答完 99 / 102 题，对照独立核对的答案表检查分数，并验证真实 MP3 播放、续播、定位、原卷图片、错题复习以及断网后的音频分段请求。

## 部署

当前站点地址：https://coserwc-cmd.github.io/Japanstudy/

仓库的 GitHub Pages 使用 `gh-pages` 分支根目录发布；环境保护规则限制了可部署分支。保留此配置，避免从 `main` 直接部署被拒绝。

`.github/workflows/pages.yml` 在 `main` 更新时检查题库、生成 `_site/`，并上传 `japanstudy-site` 构建产物。发布时运行 `python3 tools/build_site.py`，将 `_site/` 的内容提交至 `gh-pages`，由 GitHub Pages 托管。发布目录只含运行所需的静态资源，不含测试、开发工具或原版 MP3；原版录音通过官网播放，或由用户从本机导入以便离线使用。

本应用支持仓库子路径（例如 `/Japanstudy/`）：资源、manifest 和 Service Worker 都使用相对路径。发布新离线资源版本时更新 `sw.js` 的缓存名称与 `FILES`；新 Service Worker 等旧页面关闭后接管，避免中途重载考试。
